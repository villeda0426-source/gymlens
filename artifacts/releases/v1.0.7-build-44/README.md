## Snapshot Boundary

The ZIP includes current SpotLift application, server, documentation, marketing, pitch, website, asset, output, and Reddit operations source. It intentionally excludes `.env` files, credentials, Git history, dependency directories, generated distributions, and platform caches.

The snapshot includes post-release Android and web work. Their presence does not mean they shipped in iOS build 44.
